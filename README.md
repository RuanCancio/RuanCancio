## 🚀 Projetos em Destaque

📁 **[Life Knowledge Hub](https://github.com/RuanCancio)**
> Plataforma voltada para a gestão de conhecimento organizacional. Desenvolvida utilizando **Next.js**, integrada a uma modelagem relacional robusta com **PostgreSQL** e totalmente containerizada com **Docker** para garantir ambientes consistentes de execução.

📁 **[Products System](https://github.com/RuanCancio)**
> API REST completa para o gerenciamento de produtos. Construída em **Node.js** e **Express** utilizando arquitetura em camadas e banco de dados **MySQL**. O projeto conta com rotinas rígidas de testes de ponta a ponta (**Cypress**) e testes unitários (**JUnit**).

📁 **[Multi Step Form](https://github.com/RuanCancio)**
> Um formulário interativo de múltiplas etapas com foco em UI/UX responsiva. Desenvolvido com **React.js** e **Tailwind CSS**, apresentando gerenciamento complexo de estado e validação dinâmica de dados no lado do cliente.
